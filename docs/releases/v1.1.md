# Clockchain v1.1

Released 2026-10-08 (UTC) by the owner through the verified update lane
([OPERATIONS.md](../OPERATIONS.md) section 2), under the owner decision recorded
in [HOLD.md](../../HOLD.md) ("Owner decisions — 2026-10-08"). Build
`c56f73a89bcf`. Refs #6.

## What changed in the node

- Acceptance diagnostics (PR #28): the exact-image acceptance lane retains every
  `provision-v1` attempt's raw stdout, stderr and exit status, and node
  diagnostics go to stderr so a successful `provision-v1` stdout is only the
  identity JSON. No admission, provisioning or projection semantics changed.
- No rule change: `fold_version` 1, the pinned manifest, `filter_version`, the
  curator set and `max_hops` are the ones bound at launch.

## What changed around it

- Documentation: launch completion and the consumed launch authorization
  (PR #29); the salvage reconciliation and private-artifact ignore patterns
  (PR #30); the 2026-10-08 owner decisions (PR #31).
- Public read access: the read-only gateway described in
  [PUBLIC-ACCESS.md](../PUBLIC-ACCESS.md) is deployed and reachable over public
  IPv6. It serves `/public/v1` only, caches snapshots, rate-limits per client and
  never exposes the instance id, the export or any write route. The node itself
  stays on private ingress.
- Issue #6 "Pre-first-publish gates" is closed with a gate-by-gate disposition.

## Release evidence (private)

The update lane recorded: previous build `af82d9e4cd8d`; exact-image acceptance
and the populated-update scenario on synthetic data; identity gate; corpus
digest, view commitment, export bytes and store fingerprint byte-identical before
and after the deploy; `provision-v1` a no-op on the populated store; verified
backups before and after. The commitment is the one served since the owner's
2026-10-05 Delegate.

## Known limits and follow-ups

- Sealing: node-signed seals with an operator-held seal log are implemented as
  software ([SEALING.md](../design/SEALING.md) decision record) and will ship in
  a later release; v1.1 has no sealing or external anchoring.
- The gateway shares the node's read key. Revoking the gateway alone is not
  possible without rotating that key for every holder, which needs a new owner
  decision.
- The 1973 claim, its influence edge and both images remain held; generation and
  model calls remain held.
- The v0 database remains an untouched archive; its archival dump is an owner
  step.
